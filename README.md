1. Introduction
       The Stock Portfolio Management System is a Python-based project used to manage and track stock investments. It helps users maintain a record of the stocks they have purchased and calculate the total investment value.
   
2. Objective
     The main objective is to develop a simple application that helps users:
         1.Add stock details.
         2.View their stock portfolio.
         3.Update stock information.
         4.Delete stock records.
         5.Calculate the total investment amount.
3. Technologies Used
     Programming Language: Python
     Concepts: Variables, Lists, Dictionaries, Functions, Loops and Conditional Statements.
4. Working Process
    1. The program displays a menu with different options.
    2.The user selects an operation.
    3.The user enters stock name, quantity and purchase price.
    4.The program stores the stock details.
    5.Users can view, update or delete stock information.
    6.Finally, the program calculates the total investment value.
5. Example
   Suppose a user purchases:
   Stock Name Quantity  Price
     TCS        5      ₹3,5000
   Infosys     10       ₹1,500
    Wipro       8        ₹500
Total Investment:
    TCS = 5 × 3500 = ₹17,500
    Infosys = 10 × 1500 = ₹15,000
    Wipro = 8 × 500 = ₹4,000
    Total = ₹36,500
6. Advantages
    1.Easy to manage stock details.
    2.Saves time.
    3.Reduces manual calculations.
    4.Helps track investments.
    5.Improves Python programming knowledge.
7. Conclusion
    The Stock Portfolio Management System is a beginner-friendly Python project that helps users organize their stock investments. Through this project, we can understand Python programming concepts and develop basic financial management applications.
