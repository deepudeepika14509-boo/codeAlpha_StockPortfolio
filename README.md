1. Introduction
     The Stock Portfolio Management System is a Python-based application developed to help users manage and track their stock investments efficiently. A stock portfolio is a collection of stocks owned by an investor. Managing multiple stocks manually can be difficult, especially when tracking quantities, purchase prices, and total investment values.This project provides a simple and organized way to maintain stock investment records. Users can add stocks to their portfolio, view existing stock details, update information, and remove stocks when required. It also helps calculate the total investment value based on the stock quantity and purchase price.The main purpose of this project is to demonstrate the practical application of Python programming concepts in developing a real-world financial management application.

2. Objectives:
 The main objectives of this project are:
   - To develop a simple stock portfolio management application using Python.
   - To help users maintain their stock investment records.
   - To provide an option to add new stocks to the portfolio.
   - To display stock names, quantities, and purchase prices.
   - To calculate the total investment value.
   - To update and delete stock information whenever necessary.
   - To improve the understanding of Python programming through practical implementation.

3. Project Description:
     The Stock Portfolio Management System allows users to manage their investments through a simple interface.
         The application maintains important information about each stock, including:
            - Stock Name – Name of the company or stock.
            - Stock Symbol – Unique identification symbol of the stock.
            - Quantity – Number of shares purchased.
            - Purchase Price – Price paid for each share.
            - Total Value – Overall investment amount for each stock.
       The system calculates the total investment value by multiplying the quantity of shares by the purchase price.
     Formula:
        Total Investment = Quantity × Purchase Price
     For example:
         Stock Name: TCS
         Quantity: 5
         Purchase Price: ₹3,500
         Total Investment = 5 × 3,500 = ₹17,500.
4. key Process:
    1. Add Stock:
       Users can add new stocks to their portfolio by entering the stock name, stock symbol, quantity, and purchase price.
    2. View Portfolio:

    6. User-Friendly Interface

6. Working Process
     The application follows a simple step-by-step process:

Step 1: Start the Application
  The user runs the Python program.
Step 2: Display Menu
   The system displays options such as Add Stock, View Portfolio, Update Stock, Delete Stock, and Calculate Total Investment.
Step 3: Enter Stock Details
   The user enters the required information about the stock.
Step 4: Store Information
   The entered stock details are stored in the portfolio.
Step 5: Manage Portfolio
   The user can view, update, or delete stock information.
Step 6: Calculate Investment
    The system calculates the total investment value using the stored stock details.
Step 7: Exit
    The user can exit the application after completing the required operations.
